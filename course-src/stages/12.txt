Modelo mental aprofundado
Assincronismo e ensinado com uma linha do tempo. Primeiro roda codigo sincrono; depois microtasks
(Promise handlers, queueMicrotask) sao drenadas; o navegador pode atualizar a interface; tasks como
timers/eventos entram no ciclo. O objetivo e prever ordem sem decorar slogans vagos de "fila".
Promise.all, allSettled, race e any aparecem por semantica de falha. all e para "preciso de todos"; allSettled
e para operacoes independentes onde resultados parciais importam; race e any resolvem problemas
diferentes e devem ser escolhidos conscientemente.
fetch e dividido em quatro fronteiras: transporte/rede, status HTTP, parse do corpo e validade estrutural do
payload. AbortController trata cancelamento. Requisicoes concorrentes ensinam resposta obsoleta e
controle de versao/identidade.
Date.now fornece timestamps para expiracao de cache e medicao grossa; Intl.DateTimeFormat formata
datas. Temporal aparece como nota avancada porque em 2026 ainda nao e Baseline em todos os
navegadores. O curso nao obriga o aluno a usar uma API sem suporte amplo.
Erros e concepcoes que a etapa deve revelar
• Achar que fetch rejeita automaticamente em todo status HTTP ruim.
• Confundir fila de microtasks com timers.
• Usar Promise.all quando resultados parciais deveriam sobreviver.
Exemplo resolvido - buscar com validação de status
async function buscarUsuario(id) {
  const res = await fetch(`/api/users/${id}`);
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return res.json();
}
A explicacao segue um modelo deterministico: codigo sincrono esvazia a call stack; microtasks sao
drenadas; o navegador pode renderizar; entao uma task e processada e o ciclo se repete. A etapa separa
erro de rede, status HTTP, JSON invalido e payload estruturalmente invalido.
