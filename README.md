# DevPath — Site autenticado

Este é o projeto do Site autenticado, com progresso sincronizado pela conta. Para iniciar uma prévia local no Windows, execute `npm.cmd run dev` nesta pasta. Para criar a compilação de produção, use `npm.cmd run build`. Este projeto não tem `index.html`; a prévia estática independente fica na raiz do workspace.

O currículo editável da Etapa 00 fica em `course-src/stage00-preparation.mjs`, versionado junto com o Site. `scripts/revise-stage00.mjs` lê essa fonte e atualiza o catálogo. O gerador curricular do workspace também lê esse mesmo arquivo; mantenha apenas essa cópia editável.
