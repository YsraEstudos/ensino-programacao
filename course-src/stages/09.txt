Resultados de aprendizagem

• Reconhecer hoisting/TDZ sem depender de truques.

escopo léxico · closure · TDZ · hoisting conceitual · factory functions · estado privado · módulos mentais ·
WeakMap para metadados/estado privado · quando closure e suficiente
Modelo mental aprofundado
Closures sao ensinadas como funcao + ambiente lexico preservado. O aluno rastreia quais bindings
continuam acessiveis depois que uma funcao externa terminou e usa isso para encapsular estado. A meta
e entender mecanismo antes de padrões sofisticados.
WeakMap aparece como alternativa especifica quando o estado deve ficar associado a objetos sem impedir
coleta desses objetos. Nao substitui closure nem Map por padrao. O exercicio compara qual ferramenta
comunica melhor cada relacao.
O aluno tambem aprende a reconhecer closures acidentais em callbacks e listeners, preparando a etapa de
memoria e cleanup.
Erros e concepcoes que a etapa deve revelar
• Confundir closure com copia congelada de um valor.
• Criar estado oculto demais e dificultar testes.
• Usar WeakMap sem precisar de semantica de referencia fraca.
Exemplo resolvido - contador encapsulado
function criarContador(inicial = 0) {
  let valor = inicial;
  return {
    incrementar() { valor += 1; },
    ler() { return valor; }
  };
}
O aluno identifica onde valor vive e por que continua acessível depois que criarContador terminou. Isso
prepara módulos, handlers e padrões reais.
