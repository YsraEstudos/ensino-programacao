# DevPath — catálogo completo

Esta pasta é uma segunda área de trabalho Git do Site, ligada ao mesmo repositório de `devpath-publish/`. Ela contém a versão de catálogo completo e pode ter alterações locais independentes. Preserve essas alterações ao alternar entre as duas pastas.

Para iniciar uma prévia local no Windows, execute `npm.cmd run dev` nesta pasta. Para criar a compilação de produção, use `npm.cmd run build`. O currículo editável fica em `../course-src/`; os arquivos em `public/` são saídas para o Site, não fontes editoriais. Consulte `../docs/project-layout.md` antes de regenerar ou arquivar esta área de trabalho.
