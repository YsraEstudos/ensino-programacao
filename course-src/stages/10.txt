Resultados de aprendizagem

Conceitos nucleares
this · call/apply/bind · prototype · new · class · extends · campos privados · composição · this lexico de
arrow functions · call/apply/bind e limites
Modelo mental aprofundado
this e tratado como regra de chamada, nao como "dono da funcao". Metodos normais recebem this
conforme a forma de invocacao; arrow functions capturam this lexical e nao criam um novo this.
call/apply/bind conseguem controlar this de funcoes adequadas, mas nao reescrevem o this lexical de uma
arrow.
Prototipos sao mostrados como mecanismo real de delegacao. class entra depois como sintaxe ergonomica
sobre esse modelo, com campos privados e heranca usados com parcimonia. Composicao e apresentada
como alternativa quando heranca cria acoplamento desnecessario.
Exemplos rodam como ES modules para que o comportamento do topo seja previsivel e nao dependa de
scripts antigos ou this global de navegador.
Erros e concepcoes que a etapa deve revelar
• Achar que arrow e apenas sintaxe curta.
• Perder this ao extrair metodo sem bind.
• Usar heranca onde composicao simples bastava.
Exemplo resolvido - método perdido e bind
const player = {
  nome: 'Mika',
  falar() { return this.nome; }
};
const falar = player.falar.bind(player);
console.log(falar());
O aluno compara player.falar() com uma referência solta ao método. A meta é entender regra de chamada,
não decorar que this “aponta para o objeto”.
