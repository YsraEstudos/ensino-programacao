# oficina-notas

Pacote pequeno de cálculo de médias, usado por outros projetos da equipe.

- `src/index.js`: ponto de entrada do pacote.
- `src/calculo.js`: média das notas.
- `src/formatar.js`: texto da nota com vírgula decimal.
- `src/cli.js`: comando de linha (`npm start -- 6 8`).
- `test/`: testes internos com `npm test`.

Leia `ISSUE.md` antes de abrir os arquivos. Esta é uma investigação de leitura: não altere o projeto.
