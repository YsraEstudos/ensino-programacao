Modelo mental aprofundado
Coercao e um dos pontos em que JavaScript parece imprevisivel quando o aluno tenta decorar exemplos
isolados. A estrategia aqui e usar uma matriz: operacao, tipos de entrada, regra de conversao, resultado. O
aluno deve preferir conversao explicita quando a intencao de negocio poderia ficar ambigua.
Esta matriz trabalha false, 0, string vazia, null, undefined e NaN, sem pretender listar todos os falsy de JavaScript. O aluno compara || e ?? em
todos esses casos. A regra pratica e: use ?? quando o que significa "ausente" e apenas null/undefined; use
|| quando qualquer valor falsy deve acionar o fallback.
Igualdade estrita e o padrao do curso. == aparece para leitura de legado e para entender coercoes, nao
como ferramenta preferencial para codigo novo. Short-circuit entra como controle de avaliacao, com
atencao para efeitos colaterais escondidos em expressoes muito compactas.
Erros e concepcoes que a etapa deve revelar
• Usar || como fallback quando 0/false/"" sao valores validos.
• Misturar == e === sem entender coercao.
• Esconder regra de negocio dentro de uma expressao de curto-circuito dificil de ler.
Exemplo resolvido - valor padrão sem destruir zero
const quantidade = 0;
const comOu = quantidade || 10;
const comNullish = quantidade ?? 10;
console.log(comOu, comNullish);
O ponto nao e decorar operadores, mas entender que || reage a qualquer valor falsy enquanto ?? reage
apenas a null/undefined. A etapa compara false, 0, string vazia, null, undefined e NaN para impedir a regra
errada de negocio.
