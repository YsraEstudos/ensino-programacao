# Referência 22.11

`main.js` continua sendo JavaScript. O `@ts-check` mostra a ativação por arquivo e `checkJs: true` no `tsconfig` habilita a checagem do projeto; o site executa também os testes de comportamento. Os contratos protegidos importam a função JavaScript e rejeitam tipos ausentes ou ampliados para `any`.

## Transferência

Tipar por JSDoc uma função `.js` que recebe uma lista e devolve uma quantidade; acrescente contrato consumidor válido/inválido e um teste runtime.
