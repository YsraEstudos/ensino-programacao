# Change request: base de comentários alheia

Você não escreveu a base `foreign-base/`. Um relatório compartilhado pode ser lido pelo autor e deve negar acesso a outro usuário. O filtro de usuário existe na interface, mas uma rota antiga consulta apenas pelo identificador.

Entregue: regra rastreada da rota até o armazenamento; reprodução vermelha antes do patch; correção na função dona da autorização; teste para autor, terceiro e usuário anônimo; regressões do contrato anterior; diff curto e justificativa. Uma correção apenas no botão da interface reprova.
