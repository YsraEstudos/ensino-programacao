# relatorio-pedidos

Gera o relatório de pedidos dentro e fora do limite de valor.

- `src/main.js`: monta o relatório de exemplo (rode `node src/main.js`).
- `src/ui/`: apresentação em texto.
- `src/service/`: casos de uso.
- `src/domain/`: regras de negócio, sem I/O.
- `src/storage/`: repositórios.
- `test/`: `node --test` (encontra os arquivos `*.test.js`).

Leia ISSUE.md antes de abrir qualquer arquivo de código.
