# rotas-tipadas

Tabela de rotas de um painel interno e as funções que a consultam.

- `src/rotas.ts`: tabela `rotas` e o tipo `RotaId`.
- `src/navegacao.ts`: consulta de caminho e de proteção por login.
- `src/acesso.ts`: destino depois do login.
- `tsconfig.json`: configuração estrita usada pela equipe.

Leia `ISSUE.md` antes do código. Esta é uma investigação de leitura: não altere os arquivos.
