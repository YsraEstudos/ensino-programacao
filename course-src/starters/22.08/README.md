# @curso/centavos

`src/index.js` é JavaScript com JSDoc. O TypeScript verifica esse arquivo e emite `dist/index.js` e `dist/index.d.ts`.

Complete este README antes de empacotar: documente instalação ESM, as assinaturas, retornos e erros das duas funções, Node.js 24 ou posterior, licença MIT e ausência de dependências de runtime.

Valide com `npm test`, `npm run build` e `npm pack`. Instale o tarball no consumidor em `consumidor/`, execute `node main.mjs` e compile `main.ts` com TypeScript em modo strict. Confirme que o pacote contém apenas os arquivos publicados e que os caminhos `exports` existem.
