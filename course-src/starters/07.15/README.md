# biblioteca-multas

Calcula as multas de empréstimos atrasados de uma biblioteca comunitária.

- `src/regras.js`: constantes e regras de multa.
- `src/relatorio.js`: monta o relatório a partir da lista de empréstimos.
- `src/apresentacao.js`: texto para o balcão. Não decide quem entra no relatório.
- `test/relatorio.test.js`: testes visíveis. Rode com `node --test`.

Leia `ISSUE.md` antes de abrir o código. O sintoma aparece no relatório; a causa pode estar em outro arquivo.
